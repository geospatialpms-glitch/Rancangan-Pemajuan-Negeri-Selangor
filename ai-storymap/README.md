# Selangor GEO•STORY — prototaip interaktif

Prototaip portal penerokaan lima bahagian Rancangan Pemajuan Negeri Selangor, dengan kandungan rasmi dipaparkan secara langsung daripada koleksi ArcGIS StoryMaps PLANMalaysia Selangor.

## GitHub Pages

1. Cipta repository baharu di GitHub.
2. Upload fail `index.html` ke bahagian utama (root) repository.
3. Buka **Settings → Pages**, pilih **Deploy from a branch**, **main**, folder **/(root)** dan **Save**.
4. Tunggu proses deployment, kemudian buka pautan Pages yang dipaparkan.

## Nota penting

- Ini ialah versi prototaip navigasi interaktif, belum migrasi penuh semua teks, imej dan peta ke komponen tersendiri.
- Kandungan rasmi tidak ditulis semula; ia dipaparkan melalui ArcGIS StoryMaps asal. Peta dan media memerlukan capaian Internet dan tetapan perkongsian awam sumber.
- Carian Berpandu ialah padanan kata kunci untuk memilih bahagian yang relevan, **bukan** AI generatif.
- Untuk AI Assistant sebenar yang menjawab mengikut sumber rasmi, perlu indeks kandungan lengkap dan sambungan backend/API yang selamat. Jangan letak API key dalam `index.html` atau repository awam.
